プライバシーポリシー

この文書は、Android アプリ「予定フォーム」(以下「本アプリ」)における利用者の情報の扱いを説明するものです。

1. 扱う情報

  • カレンダーの予定:端末のカレンダーに保存されている予定(タイトル・日時・内容など)を、本アプリの画面に表示し、利用者の操作に応じて書き換えます。
  • 画面メモ・スクリーンショット:利用者が保存した Web ページや画像のファイルと、その一覧(タイトル・URL・作成日時・フォルダなど)を扱います。
  • Google アカウント:Google ドライブへの保存のため、利用者が許可した場合に限り、Google のログインと「本アプリが作成したファイルへのアクセス」(drive.file)の権限を使用します。

2. 情報の保存場所

  • カレンダーの予定は、端末のカレンダー(および利用者の Google カレンダー)にのみ保存されます。
  • 画面メモ・スクリーンショットは、端末内と、利用者本人の Google ドライブの「予定フォーム」フォルダにのみ保存されます。
  • 本アプリの開発者や第三者のサーバーに、利用者の情報が送信・保存されることはありません。

3. Google ユーザーデータの利用

本アプリが Google API から受け取る情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。Google ドライブへのアクセスは、本アプリが作成したファイルの保存・読み込み・削除にのみ使用し、それ以外のファイルにはアクセスしません。広告や分析の目的には使用しません。

4. 第三者への提供

利用者の情報を第三者に提供・販売することはありません。

5. 情報の削除

本アプリで画面メモ・スクリーンショットを削除すると、Google ドライブ上のファイルもゴミ箱に移動します。Google ドライブの「予定フォーム」フォルダを削除することで、保存したすべてのファイルを削除できます。Google アカウントの設定(サードパーティのアクセス)から、本アプリへのアクセス許可をいつでも取り消せます。

6. 改定

内容を変更する場合は、このページを更新します。
